# 🎅 Тайный Санта — Telegram Mini App & Бот

Красивое, новогоднее веб-приложение (Telegram Mini App) и Telegram-бот на Python (aiogram 3 + FastAPI) для организации игры в **«Тайного Санту»** с комнатами, вишлистами и умной жеребьёвкой.

---

## 🎁 Реализованные правила и особенности

1. **Комнаты для друзей (Rooms)**:
   - Организатор создает комнату (название, лимит бюджета, описание).
   - Генерируется уникальный код (`SANTA-XXXXXX`) и ссылка-приглашение для друзей.
   - Пригласительная ссылка вида `https://t.me/<Bot>?start=room_CODE` сразу открывает нужную комнату у приглашённого.

2. **Роль Администратора**:
   - Только создатель комнаты видит панель управления и может запустить игру.
   - Администратор может исключать неактивных участников до старта.

3. **Обязательные желания (Вишлист)**:
   - **Игру невозможно запустить**, пока абсолютно все участники не заполнят своё желание.
   - В лобби наглядно отображается статус каждого игрока (✅ *Желание готово* или ⏳ *Думает*).

4. **Минимум 3 участника**:
   - Кнопка запуска заблокирована, если участников меньше 3.

5. **Лимит бюджета**:
   - Указывается при создании (например: «до 2 000 ₽», «до 1 000 ₽», «Свободный»).

6. **Анти-желания**:
   - Каждый участник может указать, что ему **категорически НЕ дарить** (аллергии, нелюбимые вещи, ограничения).

7. **Защита от взаимного дарения и самодарения**:
   - Алгоритм распределения строит единый случайный замкнутый цикл (Гамильтонов цикл): $P_1 \to P_2 \to \dots \to P_n \to P_1$.
   - При $N \ge 3$ математически исключено:
     - Дарение самому себе ($A \neq B$).
     - Взаимные пары ($A \to B$ и $B \to A$).
     - Разорванные подгруппы (все участники объединены в один круг дарения).

8. **Анонимность и интерактивная открытка**:
   - Подопечный хранится в секрете.
   - В приложении участник видит интерактивную подарочную коробку с анимацией вскрытия и конфетти.
   - Бот также присылает каждому участнику в личные сообщения карточку его подопечного с вишлистом и анти-желанием!

9. **Встроенный режим тестирования в браузере (Dev Switcher)**:
   - Если открыть приложение в обычном браузере (Google Chrome, Edge, Safari), сверху появляется панель быстрого переключения между тестовыми игроками: **Иван (Админ)**, **Мария**, **Алексей**, **Елена**.
   - Можно за 1 минуту протестировать весь сценарий создания комнаты, ввода желаний и запуска жеребьёвки без необходимости заводить несколько Telegram-аккаунтов!

## 📁 Структура проекта

```
secret-santa/
├── static/
│   ├── index.html         # Интерфейс Mini App (лобби, вишлисты, карточка подопечного)
│   ├── style.css          # Новогодний дизайн (снег, стекломорфизм, анимации)
│   └── app.js             # Логика клиента, Telegram WebApp SDK, конфетти
├── bot.py                 # Telegram-бот (aiogram 3): /start, deep-link, рассылка
├── api.py                 # FastAPI бэкенд: комнаты, участники, жеребьёвка
├── config.py              # Загрузка переменных окружения
├── database.py            # SQLite база данных (aiosqlite) + алгоритм Санты
├── main.py                # Главная точка входа (запуск API + бота)
├── test_logic.py          # Автоматические тесты правил и условий
├── requirements.txt       # Зависимости Python
├── .env.example           # Шаблон конфигурации
└── README.md              # Документация проекта
```

## 🚀 Быстрый запуск

### Шаг 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 2. Запуск локального сервера (для проверки в браузере)
```bash
python main.py
```
После запуска откройте в браузере:  
👉 **http://localhost:8000**

Вы сразу сможете:
1. Создать комнату от имени **Ивана**.
2. Переключиться на **Марию** и **Алексея**, зайти в комнату по коду и написать их желания.
3. Переключиться обратно на **Ивана** и нажать **«🎲 Запустить жеребьёвку»**.
4. Открыть подарок и увидеть своего подопечного!

## 🤖 Подключение Telegram-бота и Mini App

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте нового бота командой `/newbot` и скопируйте полученный HTTP API Token.
3. Откройте файл `.env` в папке проекта и укажите:
   ```env
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
   BOT_USERNAME=ВашЮзернеймБот
   WEBAPP_URL=https://ваш-домен-или-ngrok.app
   ```
4. Включите Mini App в @BotFather:
   - Отправьте `/newapp` -> выберите вашего бота.
   - Укажите название и описание.
   - В качестве Web App URL укажите ваш HTTPS адрес (например, через ngrok: `ngrok http 8000`).
5. Перезапустите сервер `python main.py` — бот начнет принимать команды и рассылать результаты жеребьёвки!
